WordPress核心漏洞可致远程代码执行，影响超5亿网站

WordPress核心漏洞可致远程代码执行，影响超5亿网站

网络安全团队Searchlight Cyber的研究员Adam Kues近日发现一个名为“wp2shell”的WordPress核心高危漏洞。该漏洞属于预身份验证远程代码执行（RCE）漏洞，匿名用户无需任何前置条件或插件，即可在原生安装的WordPress网站上实现远程攻击。目前受影响版本包括6.9.0至6.9.4（已在6.9.5修复）以及7.0.0至7.0.1（已在7.0.2修复），预计波及全球超5亿个网站。

为防止漏洞滥用，技术细节暂未公开，但官方已发布检测工具。安全专家强烈建议管理员立即升级至最新安全版本。若无法及时更新，可采取临时防御措施，包括安装Disable WP REST API插件、利用WAF防火墙拦截针对“/batch/v1”路径的请求，或部署官方提供的自定义代码插件来限制未授权的批量API访问。

来源/漏洞检测地址：wp2shell

华硕称长鑫存储DDR5内存同频性能不及海力士，超频潜力受限

华硕称长鑫存储DDR5内存同频性能不及海力士，超频潜力受限

受全球DRAM短缺影响，中国DIY市场正加速采用长鑫存储（CXMT）的DDR5内存颗粒。尽管华硕、微星等主板厂商通过优化BIOS，已成功将相关内存的运行速率提升至8000 MT/s以上，但华硕测试指出，该产品在实际应用中仍存在局限性。

华硕表示，在相同频率下，长鑫DDR5内存的实际性能表现劣于海力士同规格产品。此外，该内颗粒存在明显的批次体质差异，且对电压调节不敏感，导致时序无法进一步收紧。这意味着长鑫DDR5虽能满足主流市场供应，但在高阶超频及性能稳定性上与传统三大内存厂仍有差距。
