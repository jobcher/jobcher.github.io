OpenAI 下调 GPT-5.6 Terra 与 Luna API 价格，Luna 降幅达 80%

OpenAI 已下调 GPT-5.6 系列中 Terra 和 Luna 两款模型的 API 价格。此次调整距离 GPT-5.6 系列于 7 月 9 日发布仅约三周，旗舰型号 GPT-5.6 Sol 的价格保持不变。

GPT-5.6 Luna 的标准 API 输入价格由每百万 Token 1 美元降至 0.20 美元，输出价格由 6 美元降至 1.20 美元，降幅均为 80%。其缓存输入价格现为每百万 Token 0.02 美元。
GPT-5.6 Terra 的输入价格由每百万 Token 2.50 美元降至 2 美元，输出价格由 15 美元降至 12 美元，整体下降 20%。缓存输入价格同步降至 0.20 美元。GPT-5.6 Sol 仍维持每百万输入 Token 5 美元、输出 Token 30 美元的价格。

OpenAI 在调价前一天发布的技术文章中披露，公司近期持续优化模型路由、负载均衡、GPU 内核、缓存和推测解码系统。其中，生产内核及相关改进令端到端模型服务成本下降约 20%，推测解码优化则使 Token 生成效率提高超过 15%。这些基础设施改进为降低推理成本提供了技术基础。

2026年7月，全国网络安全标准化技术委员会（TC260）发布《网络安全标准实践指南——人工智能 Agent 交互安全要求（征求意见稿）》。指南针对 Agent 间及 Agent 与工具间的交互安全，系统性地构建了包括身份标识、访问控制、通信安全和风险管控在内的防护体系，旨在防范身份伪造、越权访问及幻觉级联传播等安全风险。

GMF Re­s­e­a­r­ch：昨晚FO­MC最终9票支持、3票反对的维持利率政策不变。符合市场的预期，没有兑现7月加息的判断。从今天美债利率曲线的大幅扭曲变陡看2y和30y的单日扭曲程度创1987年以来历次议息会议最大——市场在一定程度上定价了“政策失误”——今天不加息，未来需要加息更多。
三张同方向反对票在FO­MC历史上比较罕见，上次三张“紧缩反对票”发生在2011年8月和9月两次FO­MC，反对的是维持超低利率的前瞻指引和反对扭曲操作——和今天一样，都发生在“货币政策框架”的变革期，也都来自轮值投票的地方联储主席（而非联储理事）。
沃什明确表示，在就业目标完成（充分就业），当看到底层通胀走高时，会更倾向于收紧政策；当看到底层通胀回落时，会更倾向于放松政策。如果对照FO­MC的声明看（就业达标、通胀仍高且63个月超标、油价反弹），未来紧缩的可能性更高。
沃什多次援引会议间歇期名义和实际收益率的大幅上行，将其视为央行减少前瞻指引、市场替代联储自行紧缩的结果。若这一风格常态化，未来的沃什式紧缩未必通过短端利率上行（加息）实现，而可能通过金融条件收紧（长端利率上行、风险资产下跌）实现。
但这样做的风险在于：若央行迟迟不行动，长端利率的上行未必来自实际利率，而可能来自通胀补偿的走阔——后者等同于市场对联储控通胀能力的不信任投票。
