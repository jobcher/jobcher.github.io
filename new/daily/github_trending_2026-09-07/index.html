CERT Polska发现MikroTik RouterOS高危漏洞且已被利用 官方紧急发布修复补丁

CERT Polska发现MikroTik RouterOS高危漏洞且已被利用 官方紧急发布修复补丁

波兰国家计算机应急响应小组（CERT Polska）于2026年9月5日发布警告，宣布在MikroTik RouterOS中发现了6个安全漏洞。其中，代号为“MikroTrick”的漏洞组合可允许攻击者在无需身份验证的情况下，通过SSH协议完全控制受影响的网络设备。官方确认上述漏洞已在公网遭到活跃利用，已有攻击者借此获取设备最高控制权并植入恶意账户。

目前MikroTik已正式发布补丁，更新至RouterOS 7.25beta3、7.24.2、7.23.4或6.49.21版本可有效防御此类攻击。系统更新后将引入“Flagged”扫描机制，自动检测并标记受攻击风险。专家建议管理员应立即安排设备升级，同步排查未知用户、异常脚本及配置变更；若无法即时更新，须立即限制SSH等关键服务的公网访问权限。

来源：CERT

AMD 组建 Rust GPU 软件团队，计划将 Rust 深入编译器、运行时与固件

AMD 组建 Rust GPU 软件团队，计划将 Rust 深入编译器、运行时与固件

9 月 5 日，Phoronix 报道称，AMD 正在组建一支专门的工程团队，推动 Rust 更深入地进入其 GPU 软件栈。AMD Senior Fellow Harsh Menon 表示，该团队的工作范围覆盖编译器、运行时、固件、GPU 架构以及软硬件协同设计。

Rust 已被列为下一代 AMD GPU 系统软件的“核心技术方向”。相关工作不仅涉及低层 GPU 软件，还包括 rustc、MIR、MLIR、LLVM 和 AMDGPU 代码生成，并计划在性能敏感和高可信组件中建立面向生产环境的 Rust 工程体系。AMD 特别强调内存安全、并发、ABI 兼容性、编译器正确性以及软硬件接口验证。招聘岗位还涉及 bare-metal 和 no_std Rust，显示 Rust 的应用目标可能深入到固件及接近硬件的层级，而不只是开发工具或外围组件。

Mullvad 将关闭公共加密 DNS 服务，转而资助 Quad9

Mullvad 将关闭公共加密 DNS 服务，转而资助 Quad9

9 月 3 日，Mullvad 宣布将停止运营其面向公众提供的加密 DNS（DoH）服务器，并把相关资源转用于资助非营利公共 DNS 服务 Quad9。Mullvad 自 2022 年开始提供公共 DoH 服务，但表示对于 Mullvad VPN 用户而言，这套服务并非必要，因为 VPN 流量本身已经加密，DNS 查询也由 VPN 内部 DNS 处理。

Mullvad 称，运营隐私导向的全球公共 DNS 是一项高度专业化的工作，与其重复建设基础设施，公司决定直接为 Quad9 提供资金支持。
