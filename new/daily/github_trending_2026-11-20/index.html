OpenSSL披露 CVE-2026-121481 缓冲区溢出漏洞，建议尽快升级修复

2026年11月18日，OpenSSL披露编号为 CVE-2026-121481 的漏洞。当调用EVP_EncodeBlock()函数传入接近INT_MAX长度的输入时，编码输出尺寸计算可能发生溢出，进而导致越界写入调用方提供的输出缓冲区，例如在openssl s_client中传入超长proxy_pass参数可能触发该问题。该漏洞影响OpenSSL 4.0.0至4.0.4（不含4.0.4）及4.1.0至4.1.1（不含4.1.1）版本，目前暂无公开在野利用记录，建议用户升级至相应修复版本。

腾讯：美国芯片出口新规短期内将延缓中国AI模型研发

腾讯：美国芯片出口新规短期内将延缓中国AI模型研发

近日，腾讯控股总裁刘炽平在财报电话会议上表示，美国政府针对中国企业访问海外数据中心所颁布的新限制措施，将在短期内拖慢腾讯下一代人工智能模型的研发进度。美国商务部于本周一出台新规，限制中国企业远程访问海外数据中心的英伟达高端芯片，并收紧了相关许可要求以防芯片经东南亚流入中国，从而堵住了此前包括腾讯和阿里巴巴在内的企业可利用的合规渠道。

尽管短期研发面临挑战，刘炽平指出，这一禁令将倒逼并加速中国本土芯片供应链的建设与成熟。面对无法继续依赖英伟达处理器的局面，国内科技企业将把更多研发资源集中于推动国产替代方案。目前，以华为为代表的国内企业正主导本土芯片的研发突破，预计长远来看，国内供应链的完善将逐步抵消外部出口管制带来的影响。

联合国国际法院11月19日裁定，缅甸在若开邦北部对罗兴亚少数民族实施了种族灭绝。这是国际法院首次裁定一个国家犯下种族灭绝罪。
法院认定缅甸安全部队杀害了约1万名罗兴亚平民，实施了广泛的性暴力，对儿童实施了极端暴力，并袭击了大部分试图逃离的罗兴亚人。
法院要求缅甸承诺赔偿，调查、起诉并惩处被认定实施种族灭绝行为的人，允许罗兴亚人“安全、自愿且有尊严地返回居住地”。
法院裁决是最终裁决且具有法律约束力，但除了向联合国安理会报告不合规行为外，没有任何执行方式。
（美联社）

东日本旅客铁道公司11月18日宣布，交通IC卡Suica的新形象角色确定为一只紫色兔子，将于2027年3月接替沿用多年的企鹅形象。公司此前邀请年轻创作者设计新角色，从中选出三个候选方案，并于9月举行网络投票。新角色的名称将另行公开征集。
获选的紫色兔子象征向未来跃进，颜色由代表安心的蓝色与代表感动的红色融合而成，同时寓意倾听周围的声音。其余两个候选方案分别是象征连接人们生活的松鼠，以及没有特定动物原型的橙色角色。
该公司计划于2027年3月举行企鹅形象的告别及角色交接活动，并希望以新角色象征Suica的功能改革。11月18日也是Suica于2001年正式推出服务的纪念日。
