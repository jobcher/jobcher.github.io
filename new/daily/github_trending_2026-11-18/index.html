五年期库存去化压力制约中国房地产市场复苏

五年期库存去化压力制约中国房地产市场复苏

当前，中国房地产市场仍面临严峻的存量去化挑战，规模相当于约五年销量的待售住宅库存成为阻碍行业回暖的核心因素。在库存高企的背景下，房企普遍陷入两难境地：若采取大幅降价策略加速出清，短期内将进一步拉低市场价格预期；若坚持稳价策略，销售回款放缓则会持续消耗企业现金流。

受此影响，行业资金面依然承压，不仅部分民营房企持续面临债务违约风险，近期连珠海华发集团等大型地方国有房企也因资金周转趋紧，传出寻求部分债务展期及信托产品兑付延期的消息。尽管各地正通过控增量、优化调整政策及推进现房销售改革等方式逐步消化存量，但整体库存压力向资金链传导的连锁反应仍未完全消除。

微软通报Microsoft 365全球中断原因

微软初步报告称，2026年11月12日至13日的Microsoft 365全球中断源于Windows网络连接处理缺陷。该缺陷随7月部署的网关服务器修复引入，运行逾三个月未显现。Teams流量切换至与Exchange Online共享的主网关，叠加约14%网关容量不可用，触发锁争用并耗尽资源，导致连接堆积、服务器无响应。
