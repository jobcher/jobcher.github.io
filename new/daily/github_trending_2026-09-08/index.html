波兰国家计算机应急响应小组（CERT Polska）于2026年9月5日发布警告，宣布在MikroTik RouterOS中发现了6个安全漏洞。其中，代号为“MikroTrick”的漏洞组合可允许攻击者在无需身份验证的情况下，通过SSH协议完全控制受影响的网络设备。官方确认上述漏洞已在公网遭到活跃利用，已有攻击者借此获取设备最高控制权并植入恶意账户。

目前MikroTik已正式发布补丁，更新至RouterOS 7.25beta3、7.24.2、7.23.4或6.49.21版本可有效防御此类攻击。系统更新后将引入“Flagged”扫描机制，自动检测并标记受攻击风险。专家建议管理员应立即安排设备升级，同步排查未知用户、异常脚本及配置变更；若无法即时更新，须立即限制SSH等关键服务的公网访问权限。

9月6日，一架执行亚马逊货运航班的波音767货机在美国佛罗里达州迈阿密国际机场降落时冲出跑道，撞上多辆地面车辆并起火，造成至少5人死亡、3人重伤、2人受伤。飞机当时从波多黎各圣胡安飞抵迈阿密。当地官员表示，事故初期尚无法确定死者是在飞机上还是车辆内。
事故导致机长和副驾驶被困驾驶舱，部分车辆内人员及一名被压在车下的人员也需要救援。超过60支消防救援队伍赶赴现场，灭火数小时后仍在处理燃油泄漏。机场航班一度受到影响，约250个航班延误。
涉事飞机由北卡罗来纳州的货运航空公司21 Air运营，机龄32年，原为客机，服役20多年后于2015年改装为货机。美国国家运输安全委员会已宣布将派调查组赴迈阿密调查，主席珍妮弗・霍门迪将负责带队。亚马逊发布声明对此惨剧表示哀悼，正在收集详情，并承诺将与当地有关部门密切合作以查明事故经过。
（CBC）
