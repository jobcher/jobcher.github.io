国内安全团队阿图因AI在网络安全领域取得多项突破

Steam Machine 首例硬件故障曝光 故障灯酷似微软“死亡红环”

日前，有海外用户在Reddit论坛反馈，其刚收到并使用仅20分钟的Steam Machine主机遭遇故障无法开机，机身出现一条红色指示灯线（即RLOD，“死亡红线”）。根据Valk/Steam官方支持页面对不同红线图案的说明，该用户的故障图案位于中部至右侧，代表GPU（图形处理器）发生故障。

由于Steam Machine采用板载焊接GPU，用户无法自行更换，只能申请售后保修或返厂维修。目前尚不清楚该故障属于偶发性个例还是首批次产品的普遍问题。

铜锣湾书店店长林荣基肺腺癌复发，7月2日19:01在台北马偕医院病逝，享年70岁。
林荣基1994年在香港创办铜锣湾书店，出版多种以中共领导人为材的图书。2015年10月，在公安部孙力军主导下，林荣基与母公司巨流传媒的桂民海、吕波、张志平、李波5人先后在深圳口岸、泰国、香港等地被中国警方控制。林荣基被宁波警方关押，电视认罪后，2016年3月以非法经营罪取保候审，被安排到广东韶山图书馆工作，当年6月14日获准返港。林返港后，决定不再返回内地，并召开记者会说明被捕经历。
港府提出逃犯条例修订草案后，林荣基于2019年4月25日前往台湾，并最终定居。
（中央广播电台）
