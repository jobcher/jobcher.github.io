🖼 中国灵活就业人数预计今年达3.2亿 占总就业人口超四成

中国灵活就业人数预计今年达3.2亿 占总就业人口超四成

《2025中国蓝领群体就业研究报告》显示，中国灵活就业人员规模预计今年将达到3.2亿人，约占总就业人口的44%，正从就业市场的“补充形式”转变为“重要支柱”。其中，家政和外卖等民生服务领域成为新增就业的主要来源。同时，蓝领平均月收入已增至6230元，与白领的收入差距持续收窄。

受访专家指出，经济结构转型、平台经济发展以及企业成本控制等多重因素推动了灵活就业人口的增长。尽管基础医保和职业伤害保障覆盖率已超80%，但该群体仍面临劳动权益保护不充分、养老和职业发展信心不足等结构性困境。未来，如何完善相关法律法规、提升新就业形态人员的社保覆盖率，将对劳动力市场结构产生深远影响。

来源：联合早报
