🖼 GitHub 推出 Copilot-SWE 模型，率先登陆 VS Code Insiders

GitHub 推出 Copilot-SWE 模型，率先登陆 VS Code Insiders

2025年9月22日，GitHub 宣布在 Visual Studio Code Insiders 技术预览中上线全新实验性模型 Copilot-SWE。该模型专为代码相关任务优化，如编辑、重构和小规模代码转换，定位为任务导向型，适配在 VS Code 内与 GitHub Copilot 的多种 Chat 模式配合使用。

Copilot-SWE 将逐步向所有 Copilot 个人用户开放。用户需安装最新版本的 VS Code Insiders，若暂未看到该功能，可稍后再行尝试。GitHub 建议结合详细提示或使用提示文件，以获得更佳效果。

官方表示，用户可在 VS Code 聊天面板中通过“报告问题”按钮直接反馈使用体验。

来源：GitHub

GitHub Copilot 宣布即将下线部分 Claude、OpenAI 与 Gemini 模型

GitHub Copilot 宣布即将下线部分 Claude、OpenAI 与 Gemini 模型

GitHub Copilot 公告显示，为保持体验的更新与高效，将于 2025 年 10 月 23 日 起在所有 Copilot 使用场景（包括 Chat、内联编辑、ask、agent 模式及代码补全）中停止以下模型的支持：

Claude Sonnet 3.7 / 3.7 Thinking → 建议替换为 Claude Sonnet 4

Claude Opus 4 → 建议替换为 Claude Opus 4.1

GPT o3 → 建议替换为 GPT-5

GPT o1 mini / o3 mini / o4 mini → 建议替换为 GPT-5 mini

Gemini 2.0 Flash → 建议替换为 Gemini 2.5 Pro

来源：GitHub Copilot 公告

OpenAI 推出 GPT-5-Codex API，登陆 GitHub Copilot 公测

2025 年 9 月 23 日，Github 宣布 GPT-5-Codex 模型开始在 GitHub Copilot 公测。该模型面向编程代理场景，支持 ask、edit 与 agent 模式。

GPT-5-Codex 将提供给 Copilot Pro、Pro+、Business 和 Enterprise 版本用户，需使用 Visual Studio Code v1.104.1 或更高版本。

Enterprise与Business需由管理员在 Copilot 设置中启用策略。
Pro 与 Pro+ 用户可在 VS Code 模型选择器中直接启用。
