1991—2020年中国儿童血铅水平：基于蒙特卡洛模拟

本文通过蒙特卡洛模拟，系统分析了1991-2020年间中国已发表文献中的儿童血铅水平（BLLs）。

数据显示，中国儿童 BLLs 在过去几十年中表现出明显的下降趋势，从1991-1995 年的 88.74 μg/L下降到 2016-2020 年的 27.32 μg/L。血铅异常率（>100μg/L）从65.7%降至2.2%，但2016-2020年仍有35.1%的儿童血铅水平超过50μg/L，仍然显著高于同期发达国家水平。

这项研究还表明，云南、贵州、山西的儿童血铅水平相对较高，大多数省份呈下降趋势，但山西在2011-2020年间出现反弹。不同年龄组儿童中，儿童血铅水平分别为 42.04 μg/L （1-3 岁）、52.88 μg/L （4-6 岁）、50.49 μg/L （7 岁及以上）。
