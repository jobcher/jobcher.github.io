Linux 内核修复 KVM 高危拒绝服务漏洞 CVE-2026-74684

Linux 内核修复 KVM 高危拒绝服务漏洞 CVE-2026-74684

Linux 内核社区日前发布修补补丁，修复了一个编号为 CVE-2026-74684 的高危漏洞。该漏洞源于 TAP 网络驱动在解析报头时存在空指针解引用缺陷，影响包括 x86 在内的多平台架构。攻击者在拥有容器内 root 权限的条件下，可通过构造特定数据包引发主机拒绝服务（DoS）崩溃，对使用 KVM 虚拟化技术的云环境构成隐患。目前 Linux 官方已对相关代码进行修正并提交主线，建议相关运维人员及时更新内核补丁。

AMD下一代旗舰显卡显存与架构信息曝光

科技频道“Moore's Law Is Dead”分析指出，AMD基于RDNA 5架构的旗舰显卡Radeon RX 10800 XT有望在实际游戏性能上超越Nvidia GeForce RTX 5090。该架构重点解决了并行扩展问题，旗舰型号预计配备多达200个计算单元、512位显存位宽及最高48GB显存。分析称Nvidia Blackwell架构芯片缺乏硬件调度器，可能在极高画质下限制其计算效率。

美国联邦最高法院8月24日支持司法部紧急申请，为联邦机构执行一项限制邮寄选票并强化选民身份核查的总统行政令开辟一定空间。
特朗普3月31日颁布行政令，要求国土安全部与社会保障署合作，为每个州创建已确认有资格投票的美国公民名单。该命令还要求缺席选票只能寄送给各州批准的邮寄选票名单上的选民，并强制使用带有唯一跟踪条形码的安全选票信封。
民主党主政的23个州和华盛顿随后以违宪为由对行政令提起诉讼。波士顿联邦地区法官塔尔瓦尼6月在裁决中同意这些地区在11月3日中期选举期间不执行总统行政令。7月25日，美国联邦第一巡回上诉法院维持塔尔瓦尼原判，继续禁止行政令实施。司法部7月27日提出紧急申请，指认塔尔瓦尼“先入为主”，因为相关联邦机构尚未依据行政令制定执行细则，要求推翻禁令。共和党主政的亚拉巴马等12州随后加入诉讼，支持特朗普政府诉求。
最高法院的裁决支持特朗普政府的说法，认为围绕行政令采取法律措施为时过早。裁决还指出，行政令并未面向起诉的地区作任何要求，因而不会对其构成“具体伤害”，但这不意味着特朗普政府今后采取的任何举动“都必然合法”。三名自由派大法官均反对最新裁决，认为其为即将到来的中期选举“不必要地注入混乱和不确定性”。
围绕该行政令的司法缠斗尚未结束。本月早些时候，另有一些选举权益组织就特朗普的行政令能否在美国所有州实施提起诉讼，法官塔尔瓦尼再次颁布禁令，阻止行政令实施。这些组织上周末还请求塔尔瓦尼宣布行政令无效，进而阻止特朗普政府后续采取任何举动。塔尔瓦尼要求政府一方25日上午前就此作出回应。只有全部相关诉讼都尘埃落定，该行政令才有望在中期选举时执行。
（新华社）

济州海洋警察署24日表示，23日上午3:04许，在济州市朝天邑新兴里附近海域，一名疑似70多岁的男性A某被发现已身亡，附近的钓友在发现尸体后报警。该男性22日被报失踪，警方正在调查该人员死亡原因。
