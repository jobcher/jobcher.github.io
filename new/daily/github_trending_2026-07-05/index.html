Steam Machine 首例硬件故障曝光 故障灯酷似微软“死亡红环”

日前，有海外用户在Reddit论坛反馈，其刚收到并使用仅20分钟的Steam Machine主机遭遇故障无法开机，机身出现一条红色指示灯线（即RLOD，“死亡红线”）。根据Valk/Steam官方支持页面对不同红线图案的说明，该用户的故障图案位于中部至右侧，代表GPU（图形处理器）发生故障。

由于Steam Machine采用板载焊接GPU，用户无法自行更换，只能申请售后保修或返厂维修。目前尚不清楚该故障属于偶发性个例还是首批次产品的普遍问题。

网信办就《互联网信息服务管理办法》修订案征求意见。
禁止实施“违法穿透、绕过国家有关机构技术措施”的活动。违反者责令限期改正，可以并处10–100万元罚款；拒不改正或者情节严重的，处100–500万元罚款，并可以责令暂停相关业务、停业整顿。
