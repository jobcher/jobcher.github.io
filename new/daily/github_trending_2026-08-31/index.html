Debian 社区议案表决：开发者可使用生成式 AI，人类负最终责任

Debian 社区议案表决：开发者可使用生成式 AI，人类负最终责任

Debian社区近日就大语言模型辅助开发议案完成投票，最终“负责任地使用生成式AI”选项胜出。新政策明确不禁止在软件开发与文档编写中使用AI工具，以协助开发者提升生产力。

该政策同时强调，所有AI辅助生成的代码和文档必须满足质量与法律合规要求，人类开发者须对其承担最终责任。此外，Debian官方鼓励但不强制要求代码贡献者披露AI工具的使用情况。

美国与委内瑞拉8月28日达成大规模石油合作协议。委内瑞拉代总统德尔西·罗德里格斯称，协议涉及17个油田，储量为650亿桶。该协议将为委内瑞拉带来超过1000亿美元的投资和超过2090亿美元的税收。
美国官员称，协议允许美国与委内瑞拉一家私营企业合作，成立新的私营企业来进行石油开发。美国将拥有新公司有效产出的55%，包括资产所有权和以成本价购买石油的权利。美国从新公司购买的石油将用于补充战略储备和军事用途。
（美联社）

尼泊尔泥石流已造成尼泊尔一侧359人死亡、910人失踪。因道路损坏，搜救工作面临困难。 中国和尼泊尔当局均警告，错坚河与普热普强藏布交汇处附近形成堰塞湖。湖水正在上涨，堰塞湖面临溃泄风险。 中国自然资源部专家表示，冰崩落体高速下泄，沿沟道裹挟冰碛物演变为碎屑流，进而汇入东林藏布形成泥石流，冲击吉隆口岸并向下游尼泊尔方向运动。根据测算，冰崩碎屑流运动速度约为每秒50米，影响距离达20多公里。 （BBC，新华社，中国水利部）

尼泊尔泥石流已造成尼泊尔一侧626人死亡、2426人失联；中国一侧7人死亡、554人失联。
搜索工作继续在中尼两国多个地点开展。尼泊尔方面重点搜索一处在建水电站。当局认为该地有百余人被困在隧道中。由于淤泥很厚，救援行动非常困难。
在中国，救援人员已进入吉隆口岸泥石流核心受灾区域开展搜救工作。视频画面显示，救援人员在敲击地面并高喊“有没有人”。
（美联社，新华社 1，2，3）
