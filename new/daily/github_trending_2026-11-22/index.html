险资专家交流：减仓接近尾声

险资专家交流：减仓接近尾声

Q：为什么险资会集中清仓科技成长股，是不看好板块基本面吗？
A：并不是机构对科技板块基本面观点发生转向，核心是险资内部一套刚性止损纪律在发挥作用，这是一个偏机械的风控机制。保险公司做权益投资大多设置回撤红线，常规的控制区间在20%到30%之间，一旦回撤超过30%，基本就要执行强制清仓，没有太多商量余地；如果投资经理坚持认为持仓值得保留，必须提交专项报告，最后由管理层审批拍板。今年4、5月不少险企选择加仓科技成长股，紧接着7、8月市场出现剧烈调整，很多持仓直接打穿止损线，触发一连串被动卖出，这类资金在下跌过程里没法接盘，反而持续砍仓，也是科技板块调整阶段很容易被忽略的资金面因素。
Q：险资如果想重新布局科技股，是不是很快就能进场形成增量资金？
A：短期很难指望险资重新成为科技成长板块的增量资金来源，风控流程和投资约束摆在前面。就算后续市场企稳，想要再度买入这类资产，首先要出现足够明确的企稳信号，同时还要重新走完内部完整的投资审批流程，不是市场稍微反弹就能直接买回。险资这套止损机制是硬性要求，经历过这一轮击穿止损线强制卖出之后，机构对于科技成长风格的风险偏好明显压低，在没有充分论证、走完内部决策流程之前，不会轻易恢复配置，所以不能简单预设科技反弹的时候险资会回来托底。
Q：险资减仓的时候，会不会优先赎回委外公募，保留自营仓位？
A：市场流传过一种说法，险资集中减仓阶段，会优先赎回公募委外产品，保住自营持仓，这个说法并不成立。自营盘和委外资金之间不存在赎回优先级，两边标准完全一视同仁，判断要不要卖出或者赎回，核心看标的本身业绩表现，以及距离内部止损线的远近，谁先触及风控条件、业绩不及预期，就优先处理谁，不会因为是自营就天然保留，也不会因为是外部委外就提前一刀切赎回，风控规则对两类资金统一适用。

成立时间较短的“红筹”企业将被禁止赴中国内地以外上市

据知情人士透露，证监会已告知部分律师事务所，将不批准成立时间较短的红筹企业赴中国内地以外上市的计划。此举加强了对境外融资的管控，并将对香港IPO市场构成打击。

此举核心在于加强对企业境外融资和资本架构的监管。一方面，防止企业通过专门设立境外主体的方式规避境外上市监管；另一方面，加强对境内资产、股权控制以及跨境资本流动的管理。尤其是2023年3月新规实施后成立的红筹企业，正在成为监管关注的重点。

结合此前相关报道，阶跃行程、月之暗面、可灵AI等明星企业可能受到影响。

中国主权财富基金拟重启对美私募股权投资，寻求增设地缘风险保护条款

中国主权财富基金拟重启对美私募股权投资，寻求增设地缘风险保护条款

据《金融时报》援引知情人士消息，中国投资有限责任公司（中投公司）正牵头推进重启对美国私募股权基金的投资，并与多家基金管理人就新增特殊风险保护条款展开磋商。受此前贸易摩擦影响，中国主权机构一度暂停了对美私募领域的新增出资；随着近期中美高层互动释放缓和信号，中方重返该市场的意愿有所回升，但地缘政治及半导体出口限制等潜在变数依然存在。

为应对中美关系恶化或欧美制裁等极端情况，中投公司要求设立无需折价抛售非流动性资产即可退出的机制。目前探讨的具体方案包括与基金退出挂钩的本票支付安排、允许跟投特定项目的“并行基金”（Sidecars），以及可选择性退出单一敏感交易而不构成整体违约的“豁免条款”（Excuse Provisions）。过往中投及国家外汇管理局曾是黑石、凯雷等美国大型私募机构的重要资金来源。
