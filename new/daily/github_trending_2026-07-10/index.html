中国6万亿债务化解取得阶段性进展 地方财政迎缓解契机

彭博社汇编数据显示，在江苏、浙江、山东等大省带动下，截至今年6月底，中国定下的6万亿元（人民币，1万1416新元）隐性债务置换额度已经用了约94%，说明这轮债务处理接近尾声。

中国在2024年底批准，分三年（2024至2026年）实施的地方政府债务限额增加计划，每年两万亿元，核心目标是发行地方政府债券来置换原有的隐性债务，从而大幅减轻地方利息负担，腾出资金发展经济。

彭博社报道指出，若继续保持当前发行速度，这项三年期债务置换计划的剩余额度可能在本月或下月用完。

OpenAI 正式发布 GPT-5.6：三层模型面向 ChatGPT、Codex 与 API 开放

OpenAI 发布 GPT-Live

OpenAI 于 2026 年 7 月 8 日发布 GPT-Live，并开始向全球 ChatGPT 用户分阶段推出这一代新语音模型。首发版本包括 GPT-Live-1 和 GPT-Live-1 mini，其中付费个人计划默认使用 GPT-Live-1，免费用户默认使用 GPT-Live-1 mini。

与此前按回合等待用户停顿后再响应的语音模式不同，GPT-Live 采用全双工架构，可以在用户说话时继续监听并实时输出，从而改善打断、停顿判断和连续接话的自然度。官方同时表示，当问题需要网页搜索、较深推理或更复杂的任务处理时，GPT-Live 会将相关工作委托给后台前沿模型完成，首发阶段后台使用的是 GPT-5.5。

这一能力已经接入新版 ChatGPT Voice。按照 OpenAI 的说明，新版语音支持更自然的对话节奏、更高的智能等级选择，以及天气、股票、体育等场景的可视化卡片展示，同时继续支持搜索、记忆，以及与文字和图片混合使用。

可用范围方面，GPT-Live 正在 iOS、Android 和 ChatGPT 网页端向消费者计划逐步推出，但 ChatGPT Business、Enterprise 和 Edu 工作区首发暂不提供。另外，Live 在上线初期还不支持视频和屏幕共享，这些能力目前仍保留在旧版 Advanced Voice 中；OpenAI 还表示，API 支持将随后推出。
