AppleCare作为一项保障计划对于经常手滑的用户能提供相比保外维修较为便宜的维修价格。
*1 通常情况该计划的购买在新购入设备后的7天内可以自行在线上购买60天内可以前往直营店进行检测后补买。不过对于线下直营店有一条不成文的规定，即便超过60天只要设备仍在有限保修内通过诊断和外观检查后依然可以补买计划。

*1: 对于该AppleCare的政策来自中国大陆AppleCare权益介绍，权益称用户可以在60天内前往线下补充计划。
*2: 该尝试仅作为单个员工建议不意味着一定能够补充。

波兰宪法法院近日爆发领导权争议。
今年以来，总理图斯克领导的执政联盟占多数席位的波兰众议院先后选出8名宪法法院法官，但其中5人的法官身份未获与反对党法律与公正党结盟的总统和宪法法院院长承认，无法参与案件审理。
政府10月30日宣布暂停院长和副院长职务一个月，由法官安娜·科尔温－皮奥特罗夫斯卡暂时主持法院工作。科尔温－皮奥特罗夫斯卡是上述未获总统和院长承认的5人之一。总统纳夫罗茨基中断出访行程返回华沙，与部分法官发生激烈争执，甚至一度发生推搡。
纳夫罗茨基称波兰宪法秩序遭到破坏，宪法机构遭“强行占领”，呼吁与议会各派代表举行紧急磋商，以稳定政治局势、恢复宪法秩序。图斯克指责法律与公正党和总统破坏法治。他表示，即使是总统，也无权向法官下达命令或恐吓法官，政府将保障宪法法院的安全和正常运转。
科尔温－皮奥特罗夫斯卡计划于11月3日召开法官大会，讨论宪法法院预算等事宜。波兰媒体分析说，部分法官因不认可会议合法性而拒绝参加，会议可能因出席人数不足而无法通过有效决议。
此事引发反对党支持者在该法院外聚集抗议，部分抗议者与警方发生冲突，3名闯入法院院区的抗议者被警方控制，冲突造成多人受伤。
欧盟委员会10月31日表示，正密切关注波兰宪法法院局势，强调波兰应确保该法院依法正常运转，同时指出波兰众议院有权选举宪法法院法官。欧洲议会保守派和改革主义者党团则批评图斯克政府干涉司法独立。
（新华社）
