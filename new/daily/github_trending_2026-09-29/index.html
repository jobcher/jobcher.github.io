英伟达拟扩大对华芯片销售，黄仁勋政治影响力引发业界担忧

Anthropic 发布 Claude Sonnet 5.5：速度提升 30%+，单任务成本最高降低 30%

Anthropic 发布 Claude Sonnet 5.5：速度提升 30%+，单任务成本最高降低 30%

Anthropic 于 9 月 28 日发布 Claude Sonnet 5.5。官方称，新模型相比 Sonnet 5 生成速度提升超过 30%，在完成相同任务时通常消耗更少 Token，单任务成本最高可降低约 30%。模型定价保持不变，输入为 2 美元/百万 Token，输出为 10 美元/百万 Token。

Sonnet 5.5 的主要提升集中在编程和知识工作。在 Terminal-Bench 4.0 上得分 70.6%，高于 Sonnet 5 的 10.3%；GDPval-AA 得分 1844，与 Opus 5.5 的 1846 接近。Anthropic 将其定位为 Opus 5.5 的低成本、高速度补充，主要面向日常开发、Bug 修复以及文档、幻灯片和表格生成。

Claude Sonnet 5.5 已上线 Claude 全平台，同时登陆 AWS、Google Cloud 和 Microsoft Azure，API 模型名为 claude-sonnet-5-5。

🧧【长江宏观宋筱筱团队】9.28国常会简评

🧧【长江宏观宋筱筱团队】9.28国常会简评

9月28日，国常会提出一揽子支持内需的政策方向。

【1】其中最大亮点是，明确提出“用好地方政府债务结存限额”。近两年来，财政连续使用政府债结存限额。2022年9月，安排5000多亿元专项债结存限额支持在建项目，年内形成更多实物工作量；2024年10月，安排4000亿元支持地方化债和消化拖欠企业账款；2025年10月，安排5000亿元，其中3000亿用于化债，2000亿用于经济大省符合条件的项目建设。

【2】目前的结存限额来看，地方一般债、专项债分别有约5569亿、6074亿的限额空间，合计约1.2万亿。但需关注一个技术性细节，2025年安排5000亿元下达地方后，最终结存限额并未同步减少5000亿，或因其他政府债到期，没有足额用于再融资偿还。

【3】除此以外，内需方面的主要亮点还包括：1）再提稳定房地产市场政策措施；2）加快各类债券发行使用进度…提高投资审批效率；3）综合运用并适时调整货币政策工具，增加再贷款额度等。

【4】在三季度末的时间点再提稳内需，主要着眼点或仍在全年目标的完成。而从当前宏观经济运行背景来看，二季度GDP已降至4.3%，且依高频数据拟合的Q3GDP同比增速相比Q2可能没有明显上升，全年实现增长目标存在不确定性，以增量政策夯实经济目标实现的必要性在逐步提升。
