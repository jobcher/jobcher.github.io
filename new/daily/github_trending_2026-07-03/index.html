GitHub Copilot 接入 Kimi K2.7 Code

首个可选开源权重模型上线GitHub，Kimi K2.7 Code 现已在 GitHub Copilot 中进入 GA，可在 Copilot 模型选择器中作为可选模型使用。这是 Copilot 首个作为可选项提供的 open-weight 模型，GitHub 将其定位为面向编程工作流的低成本选择。模型由 GitHub 托管在 Microsoft Azure 上，并按提供方标价进行用量计费。

GitHub Copilot 的模型生态继续从封闭前沿模型扩展到开源权重模型。对个人开发者来说，它提供了一个更便宜的代码模型选择。

↩️ Anthropic回应Claude Code事件：系防滥用实验并将全额回滚

LoopDNS资讯播报:

技术人员指称Claude Code隐蔽植入用户检测机制 近日有技术人员在Reddit发文透露，Anthropic自2026年4月的Claude Code 2.1.91版本起，隐蔽植入了针对中国用户的检测逻辑。当用户启用代理时，该工具会检查系统时区与代理域名，并通过在系统提示词中改变日期格式和微调Unicode符号，向官方回传用户是否位于中国或属于国内AI实验室。 尽管该机制目的可能用于防范非法转售与模型蒸馏，但由于相关检测代码经过混淆且未在更新日志中公开，这种在不知情下收集并回传配置的行为，已引发开发者对隐私越界及系统安全的担忧。…

Anthropic回应Claude Code事件：系防滥用实验并将全额回滚

针对近期开发者指责Claude Code隐蔽植入检测机制一事，Anthropic相关负责人通过社交平台做出回应：该机制为今年3月启动的一项技术实验，旨在防范未经授权的账号转售滥用，并保护模型免受非法蒸馏。

发言人透露，目前团队已落地更强效的缓解方案，且早已计划移除该实验性检测。目前相关回滚代码已完成合并，预计将在明日发布的最新版本中完全撤销这一机制。

特朗普及其家族2025年从加密货币相关商业交易获利超过14亿美元。
根据特朗普向政府道德准则办公室提交的2025年法定财务申报文件，特朗普的公司从他和儿子们联合创办的世界自由金融公司获得近8亿美元。此外，特朗普还通过发行“特朗普迷因币”获得6.35亿美元。
此外，特朗普还从多项法律诉讼和解中获得约8650万美元收入，通过将其名字授权给海外房地产开发商获得5200万美元。特朗普还从海湖庄园等俱乐部获得约3亿美元收入。
白宫发言人否认特朗普及其家人存在利益冲突，表示特朗普通过行政行动使美国成为“全球加密货币之都”。特朗普本人亦强调，他不受联邦利益冲突法规约束。
特朗普在上台前批评加密货币，甚至曾形容比特币是一场“骗局”以及“一场等待发生的灾难”。但在重返白宫后，特朗普对加密货币行业采取友善立场。除了家族企业发行代币外，其任命亲加密货币行业的保罗·阿特金斯为美国证券交易委员会主席。阿特金斯上任后已推动该机构逐步摆脱前任依靠执法推行严格监管的做法。
路透社估计，自特朗普重返白宫后，特朗普家族已从加密货币相关项目赚取至少23亿美元。
（BBC，路透社）
