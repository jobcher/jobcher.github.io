Cloudflare 中断了与 Hurricane Electric 的对等互联

Cloudflare 中断了与 Hurricane Electric 的对等互联

8 月 17 日，Hurricane Electric（AS6939）公开路由系统显示，其与 Cloudflare（AS13335）之间部分 BGP 会话处于非 Established 状态，部分连接显示为 CONN，表明相应 BGP 会话当前未正常建立。

与此同时，双方并未全面断开。HE 页面中仍可看到大量处于 ESTAB 状态的 Cloudflare 会话，其针对 AS13335 的 IPv4、IPv6 路由过滤配置也仍然存在。
Cloudflare 官方状态页目前未发布与 Hurricane Electric 互联相关的事故通告。

Linux 7.2正式版发布：全面提升I/O性能与硬件兼容性

LoopDNS资讯播报:

严重/需要注意的：爱快（iKuai）路由系统疑似存在远程利用漏洞，部分用户反馈 DNS 遭篡改。 8月13日至8月14日，有爱快（iKuai）用户在论坛集中反馈，其路由设备的 DNS 配置在未经管理员操作的情况下被异常修改，部分用户随后出现网页访问内容被劫持、跳转异常等现象。 目前用户反馈的异常特征具有较高一致性：受影响设备的首选 DNS 被修改为 43.98.194.101，备用 DNS 被修改为 43.98.163.207；同时，系统中的 DNS 加速服务被开启“第三方代理模式”，其中上游首选 DNS…

爱快官方确认近期遭持续攻击，紧急发布安全更新；部分用户反馈设备被云端下发重启后异常

此前我们曾报道，8 月 13 日至 14 日期间，多名爱快（iKuai）用户集中反馈，其路由设备的 DNS 配置在未经管理员操作的情况下遭到异常修改。部分设备即便手动恢复 DNS 设置，也会在数分钟后再次被篡改。值得注意的是，相关设备的传统登录日志中并未发现明显的异常管理员登录记录。

目前，爱快官方已就此次事件发布安全公告，并确认近期爱快系统正遭受“持续的攻击”。

根据爱快发布的《关于近期爱快系统安全更新及排查建议的公告》，目前攻击的具体源头仍在进一步溯源中，但官方已经掌握部分攻击特征，并采取了相应的反制措施。

爱快同时确认，此次攻击主要针对设备的 DNS 功能，攻击者还会对部分路由设备实施“强制断网”。通过对异常行为样本进行分析，官方目前已定位到部分受影响客户，技术支持团队正在与相关用户逐一沟通，对受影响设备进行清理和安全加固。

针对本次安全事件，爱快表示已经报案，并联合安全厂商开展专项调查。同时，官方紧急发布了 3.7.24 修复版本，并要求相关设备升级至 4.0.307 及以上版本，以降低遭受攻击的风险。

不过，截至目前，爱快尚未公开此次攻击所利用的具体漏洞类型，也未公布相关 CVE/CNVD 编号、漏洞技术细节、完整受影响版本范围，以及攻击者究竟通过何种路径获得设备控制权限。

与此同时，事件处置过程中又出现了新的用户反馈。部分爱快用户表示，其处于在线状态的设备在没有现场管理员主动执行重启操作的情况下，被爱快云平台下发了重启指令。

已有部分用户反馈称，设备在此次远程重启后出现异常，包括无法正常启动、启动过程异常，以及设备成功启动后仍无法恢复联网等情况。
