LoopDNS资讯播报:

突发：英伟达董事会恢复黄仁勋CEO职务。 来源：Nvidia Newsroom

综合WIRED等传媒报道，黄仁勋在重返英伟达后的首次全员大会上，对近期发生的事作出一次全面回应，透露自己每天接受一个半小时的心理治疗，承认管理风格存在问题并拒绝传统接班人计划。

黄仁勋开场先对全员道歉，并表示人生中最艰难的一次会议是与妻子的谈话，而当下是最艰难的一次公司会议。

他承认管理风格存在问题，有时会伤害员工、贬低员工，甚至削弱员工的自主性和工作能力。承诺提高对自己的要求，接受360度绩效评估。

黄仁勋再次强调，公司规则面前人人平等，但员工违反行为准则，并不意味着公司必须立即将其解雇，需要视情况而定。公司需要为所有女性员工创造并持续维护一个安全的工作环境。

员工大会最重要的部分，在于公司继承者的问题。他表示，英伟达已建立自主运行机制，不应该因为CEO离开就失去执行能力。黄仁勋认为自己是科技行业任职时间最长的CEO之一，因此公司组织模式已经形成了独特的运行机制。

黄仁勋还专门否认了特朗普对其复职的推动作用，认为董事会是按照自身职责作出复职决定，而非政府指示。自己会尽力向特朗普提供信息，帮助总统作出符合美国国家利益的决策。无论下一任美国总统是谁，都会这样做。不希望英伟达被视为一家具有党派立场的公司，并表示自己不喜欢公司内部过多讨论政治，更希望员工把精力放在工作上。

来源：外汇交易员

GMF 市场追踪

今年2月IEEPA关税被最高法院推翻后，美方用两项301调查来接续。一项是7月落地的"强迫劳动"301关税，对60个国家征收10-12.5%，对华税率是12.5%。另一项就是本次报道的产能过剩301。Greer在11月20日已公开表示该调查的结果"很快"公布。增量信息只有时间提前到本周以及可能带升级条款。

吉隆坡协议的休战在2027年1月10日到期，美方178 项301豁免和港口费暂停到1月9日到期。休战若延续，两项301调查的累计关税大概率维持在 12.5%–20%区间，若不延续，则20%的约束随之失效，美方理论上可以继续上调。
