Qwen 发Qwen3.8-Max-0902，强化编程与 Agent 能力

Qwen 发Qwen3.8-Max-0902，强化编程与 Agent 能力

9 月 2 日，阿里 Qwen 发布 Qwen3.8-Max 的升级版本 Qwen3.8-Max-0902。模型规模保持 2.4T 参数，上下文窗口仍为 100 万 Token。本次更新主要针对 Coding 与 Cowork 继续进行后训练，重点提升复杂软件工程、企业任务、科研工作流以及长时间自主执行能力。

据阿里公布的自测结果，0902 版本在 8 项编程评测中均高于此前版本。其中 TerminalBench 3.0 从 11.3 提升至 29.0，DeepSWE 1.1 从 56.6 提升至 69.3，QwenSWEbench V2 从 55.1 提升至 70.0；JobBench 从 53.4 提升至 64.0。部分项目超过 Claude Opus 5，但多数编程评测仍低于后者，目前这些结果尚主要来自阿里内部测试。

QwenCloud 将该版本标记为 qwen3.8-max-0902，别名为 qwen3.8-max-2026-09-02。模型支持文本、图像和视频输入，并保留 Thinking、Function Calling 与内置工具能力。官方同时表示视觉理解也有所改进，包括图表推理、文档解析和多模态感知。

Qwen3.8-Max-0902 已通过 QwenCloud API 上线。价格为每百万 Token 输入 2 美元、输出 6 美元，显式缓存命中 0.17 美元，隐式缓存命中 0.25 美元。

来源：Qwen 官方 X 公告

Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1

Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1

9 月 1 日，Anthropic 发布 Claude Fable 5.1 与 Claude Mythos 5.1。两者基于相同底层模型，但采用不同安全限制：Fable 5.1 面向普通用户和企业开放，Mythos 5.1 则主要面向经过审核的网络安全与生命科学研究机构。

Fable 5.1 重点提升编码、知识工作、长期 Agent 任务与科研能力。Anthropic 公布的测试中，其 Terminal-Bench-Science 0.1 得分为 52.6%，高于 Fable 5 的 24.7%；Terminal-Bench 4.0 得分为 55.8%，Mythos 5.1 在解除部分安全限制后达到 60.9%；CursorBench 3.2.0 得分为 73.4%。

科研能力也是本次升级的重点。Anthropic 称，Mythos 5.1 在蛋白质设计实验中实现接近 50% 的有效结合体命中率，并将部分计算生物学模型的推理速度提高最高 2.5 倍；Fable 5.1 还利用 NASA Magellan 雷达数据生成了新的金星高分辨率高程图。

Fable 5.1 已在 Claude、Claude API 以及 AWS、Google Cloud 和 Microsoft Azure 等平台上线，API 模型名为 claude-fable-5-1。输入和输出价格维持每百万 Token 10 美元和 50 美元，但缓存读取价格降至每百万 Token 0.25 美元，Anthropic 估算典型工作负载成本可降低约 25%，高 Agent 化任务最高降低约 45%。Mythos 5.1 仅通过 Anthropic 的可信访问计划向经过审核的网络安全防御人员和生命科学专业人士提供。目前访问范围仅覆盖一组美国组织，Anthropic 计划进一步扩展至美国及其他国家的合作伙伴。

来源：Anthropic 官方公告：Claude Fable 5.1 and Mythos 5.1

Proton 再次发生服务故障，几乎所有核心服务受到影响

Proton 于北京时间 2026 年 9 月 1 日晚间 出现大范围服务异常，官方状态页面显示，多个核心产品均受到不同程度影响，包括 Proton Mail、Proton VPN、Proton Calendar、Proton Drive、Proton Pass、Proton Wallet 以及 Lumo 等服务。

此次故障影响范围较广，Proton Mail 部分用户出现邮件收发异常，Web 应用、移动端应用、桌面客户端以及 Bridge 等组件均报告部分中断（Partial Outage）。部分用户反馈无法正常访问服务，网页端持续出现重试提示。

与此同时，Proton VPN 的免费服务器、普通服务器、Secure Core、流媒体服务、客户端及浏览器扩展也受到影响；Proton Calendar、Proton Drive、Proton Docs、Proton Pass 等服务同样出现部分故障。

Proton 官方于北京时间 9 月 1 日 20:37 发布调查公告：

“我们已注意到少量用户可能正在访问 Proton 服务时遇到问题，团队正在调查该问题，并将在此页面尽快发布最新进展。对于造成的不便，我们深表歉意。”

随后，北京时间 9 月 1 日 22:42，Proton 更新状态表示：
“我们仍在继续调查该问题。”

截至目前，Proton 尚未公布具体故障原因，官方仍处于调查阶段。状态页面显示，大部分受影响服务仍标记为“Partial Outage（部分中断）”。
