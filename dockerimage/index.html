docker image 镜像上传

登入 docker hub，在https://hub.docker.com上注册你的账号。

1docker login
2username：#输入你的用户名
3password：#输入你的密码

上传镜像

1docker tag nginx:hugo sjtfreaks/hogo-nginx:v1
2docker push sjtfreaks/hogo-nginx:v1
