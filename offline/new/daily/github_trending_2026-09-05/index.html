华为发布“τ芯片”最新研究 提出3D堆叠重构电路新思路

华为半导体负责人何庭波于9月4日在ChinaXiv发布论文《Huawei’s τ Chip Was Supposed to Melt?》，进一步阐述了华为“τ芯片”及LogicFolding技术。该研究指出，芯片功耗不仅来自计算，更来自数据传输；通过将电路重构为上下层结构，不仅大幅缩短了信号传输距离与延迟，还显著降低了数据移动所产生的能耗。

论文数据显示，应用该技术的麒麟2026芯片晶体管密度提升约55%，在同等性能下，NPU与GPU功耗分别下降66%和58%。华为通过热感知布局和源头降耗，回应了行业关于3D堆叠“高密度等于高发热”的质疑。但何庭波也表示，混和键合、应力控制及EDA设计等技术挑战仍需3至5年时间持续探索与突破。

OpenAI 正式发布 GPT-6 Astra

OpenAI 正式发布 GPT-6 Astra

9 月 3 日，OpenAI 正式发布新一代旗舰模型 GPT-6 Astra，称其为目前能力最强、对齐程度最高的模型。Astra 重点提升计算机操作、浏览器使用、软件工程、网络安全、科学研究和专业知识工作，并强化跨应用执行多步骤任务的能力，可直接生成和处理文档、表格、演示文稿及网站。

OpenAI 公布的评测显示，GPT-6 Astra 在 OSWorld 2.0 上取得 72.6%，高于 GPT-5.6 Sol 的 65.7%，单项任务耗时约减少 47%；FrontierMath Tier 4 达到 97.6%，ARC-AGI-3 达到 99.9%，ExploitBench 达到 100%。OpenAI 注明，这些成绩采用各模型的最高 effort 设置，实际 ChatGPT 产品表现可能因系统提示词和工具配置不同而有所差异。

Astra 同时成为 OpenAI 首个达到 Preparedness Framework 中“Critical”网络安全能力阈值的模型。OpenAI 表示，该模型已具备发现未知漏洞并开发利用链的能力，因此正式版本对高风险网络安全任务设置了更严格限制，更高级能力将通过 Daybreak 等受控渠道逐步开放。

GPT-6 Astra 已首先向部分机构开放，并将在未来数日陆续提供给 ChatGPT Plus、Pro、Business 和 Enterprise 用户，同时进入 OpenAI API 与 AWS。Pro、Business 和 Enterprise 用户还将获得 GPT-6 Astra Pro。API 标准价格为每百万输入 token 10 美元、输出 token 50 美元；Fast 模式最高可提供 2.5 倍处理速度，价格为标准模式的两倍。

针对此类大规模违规访问和技术套取行为，美政府及部分业内人士呼吁出台严厉措施打击知识产权盗窃。美方部分安全专家强调，虽然合法合规的蒸馏属于正常竞争，但通过暗黑产业链绕过监管与安全防护进行模型克隆，不仅损害研发者利益，也加剧了AI技术的滥用隐患。

想租 GPU 跑模型，看了几家平台，价格差得还不少，到底哪个价才算正常？

Computable GPU Index 是一个开源的 GPU 价格指数工具，会把多家平台的公开报价整理成 GPU 云算力价格 参考指数。目前可以看 H100 SXM、H200 SXM、B200 和 B300，每 15 分钟更新一次。

租 GPU 前可以先看看现在的市场价，拿到供应商报价后也能顺手对一下，做训练预算时心里更有数。

它的计算方法、历史数据和代码都公开，还提供 REST API 和 MCP，Claude 这类支持 MCP 的 AI 客户端也能直接查最新价格。
