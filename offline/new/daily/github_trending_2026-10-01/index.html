OpenAI指责月之暗面涉嫌大规模提取其模型数据

此次事件反映出全球大模型领域的竞争正持续加剧。OpenAI已将相关威胁信息同步至行业伙伴及美国监管机构；月之暗面方面暂未对此作出回应。此前，中方及部分行业人士曾明确否认类似的数据抽取指控，并指出相关批评存在泛化安全问题、借机打压开源生态与外部竞争对手的倾向。

Anthropic：GLM-5.3 已具备较强自主漏洞利用能力

Anthropic：GLM-5.3 已具备较强自主漏洞利用能力

Anthropic 发布最新安全研究，称智谱 Z.ai 的 GLM-5.3 已经可以自主完成较复杂的端到端漏洞利用。在 ExploitBench 测试中，GLM-5.3 在 410 次尝试中成功完成 50 次端到端利用，与 Anthropic 自家的 Claude Mythos Preview 的 56 次已经处于接近水平。
在人工参与的测试中，研究人员还利用 GLM-5.3 找到了多个此前未知的浏览器漏洞，并将其组合成可以实际运行的攻击链。Anthropic 表示，GLM-5.3 默认会拒绝明显恶意请求，但其安全限制在模拟测试中可以被较容易绕过，而开放权重也意味着模型的拒绝机制可以被进一步修改。

这并不只是 Anthropic 单方面的判断。美国 NIST 旗下 CAISI 此前也将 GLM-5.3 称为目前网络安全能力最强的开放权重模型，不过其综合网络安全能力仍被评估为落后当前美国前沿模型约四个月。需要注意的是，CAISI 对部分美国模型的测试关闭了安全限制，并包含仅向受信任用户开放的版本，因此能力对比和实际可获得性并不是同一回事。

Anthropic IPO文件曝光：2025年净亏损420亿美元，未来算力承诺超5180亿美元

Anthropic IPO文件曝光：2025年净亏损420亿美元，未来算力承诺超5180亿美元

Anthropic 的 IPO 文件披露了其高速增长背后的巨额成本。2025 年公司收入约 46 亿美元，营业亏损约 80.6 亿美元，净亏损达到约 420 亿美元。其中约 340 亿美元来自融资工具重新估值产生的会计费用，并不等同于实际现金支出。

进入 2026 年后，Anthropic 的收入增长明显加速。第二季度收入已经达到约 115 亿美元，公司同时向投资者表示，预计连续第二个季度实现调整后营业利润为正。不过这一指标并不等同于 GAAP 净利润或自由现金流已经转正。

Anthropic 已于今年 6 月秘密提交美国 IPO 申请，目前尚未正式上市。路透社报道称，其潜在上市估值可能超过 2 万亿美元。

OpenAI Codex 与 ChatGPT Work 负责人 Thibault “Tibo” Sottiaux 9月29日在 X 上宣布，200美元/月的 ChatGPT Pro 订阅将于9月30日重新向新用户开放，同时调整使用额度的计算方式。按照 API 标价金额折算，新版套餐包含的额度约为此前200美元 Pro 套餐的一半。

Tibo 强调，这并不意味着用户实际能够完成的工作量减少一半。OpenAI 不会重新引入5小时使用限制，同时计划通过提高模型效率和持续降低 API 价格，让相同额度能够完成更多任务。此前 GPT-6 Sol 与 Luna 的 API 价格已经下调50%。

他还表示，OpenAI 不希望为了让订阅套餐看起来拥有更高额度而人为维持较高的 API 标价。长期方向是继续降低 API 成本并提高模型能力，使按量购买 API 与订阅制之间的单位价格差距逐步缩小。9月30日还将公布更多不消耗使用额度的订阅功能。

中国加强催收行业监管 个人不良贷款处置效率面临放缓

针对庞大的个人不良债务危机，中国近年来允许金融机构向资产管理公司批量转让个人不良贷款。然而，随着公安部门对催收公司加强执法监管与审查，行业迎来合规整顿，部分催收机构不得不裁员或关停，导致个人不良债务的回收率受到影响，处置效率明显放缓。

催收环节的受阻使得不良资产投资机构和资产管理公司的采购态度趋于谨慎，也加大了商业银行进一步清理资产负债表不良债务的难度。业内人士分析，由于缺乏全国性的个人破产制度，加上部分借款人履约能力不足，个人不良资产处置仍高度依赖经济周期的整体复苏与市场退出渠道的顺畅。
