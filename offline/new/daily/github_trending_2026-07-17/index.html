华硕称长鑫存储DDR5内存同频性能不及海力士，超频潜力受限

华硕称长鑫存储DDR5内存同频性能不及海力士，超频潜力受限

受全球DRAM短缺影响，中国DIY市场正加速采用长鑫存储（CXMT）的DDR5内存颗粒。尽管华硕、微星等主板厂商通过优化BIOS，已成功将相关内存的运行速率提升至8000 MT/s以上，但华硕测试指出，该产品在实际应用中仍存在局限性。

华硕表示，在相同频率下，长鑫DDR5内存的实际性能表现劣于海力士同规格产品。此外，该内颗粒存在明显的批次体质差异，且对电压调节不敏感，导致时序无法进一步收紧。这意味着长鑫DDR5虽能满足主流市场供应，但在高阶超频及性能稳定性上与传统三大内存厂仍有差距。

皮尤研究中心最新调查：中国全球好感度首超美国

分析指出，随着全球对美国领导人信心的持续下降，以及外界对美国外交政策的担忧，美国的国际形象有所恶化。尽管在尊重个人自由的指标上美国依然领先，但两国之间的差距正在缩小。该调查于今年2月至5月期间进行，共覆盖超过4.2万名受访者。

SpaceXAI 开源 Grok Build

SpaceXAI 开源 Grok Build

SpaceXAI 于 7 月 15 日宣布开源终端编程智能体 Grok Build，并将源代码发布至 GitHub。此次开放的是 Grok Build 的代理框架、命令行工具和终端界面，不包括 Grok 4.5 等模型的权重。

公开代码覆盖上下文组装、模型响应解析、工具调用分发、文件读写、代码搜索与命令执行，同时包括全屏终端界面，以及 Skills、插件、Hooks、MCP 服务器和子智能体等扩展机制。项目主要使用 Rust，第一方代码采用 Apache 2.0 许可证。

开发者可以自行编译 Grok Build，并通过 config.toml 接入本地模型或其他兼容推理服务。Grok Build 还支持交互式终端、脚本及 CI 无头运行，并可通过 Agent Client Protocol 嵌入代码编辑器。

需要注意的是，该 GitHub 仓库由 SpaceXAI 内部代码库定期同步，目前不接受外部代码贡献。此次开源发生在 Grok Build 因上传用户代码仓库和数据留存问题引发争议之后

Mozilla发布2026开源AI报告：开源与闭源模型差距缩至3.3%

Mozilla于7月14日发布《2026年开源AI现状报告》。数据显示，截至2026年3月，开放权重与闭源模型的平均能力差距为3.3%，在编码和通用知识等领域基本持平，但在推理和智能体任务上仍有差距。此外，GPT-4级模型的API价格在36个月内降至原先的五十分之一。在OpenRouter平台6月的API月调用量中，前五名均为开源模型，其中DeepSeek V4 Flash以18.4T Tokens登顶。

尽管79%的开发者已采用开放模型，但受限于性能、集成和维护等运营难题，仅有51%的开放模型团队能成功将其部署至生产环境，低于闭源模型的63%。

来源：Mozilla

乌克兰国防部长米哈伊洛·费多罗夫7月15日被免职，引发抗议活动。
费多罗夫被视为现代化军事技术推动者。他指责武装部队总司令亚历山大·瑟尔斯基阻碍了必要的改革。费多罗夫称，虽然他愿意与瑟尔斯基合作，但其提出的所有倡议都开始受到阻碍，他不知道怎么样才能赢得战争。
瑟尔斯基未公开露面，但在社交媒体上感谢费多罗夫，希望他继续留在乌克兰团队。但瑟尔斯基未详细说明。
乌克兰多地发生抗议活动，以年轻人居多的数千名抗议者不满瑟尔斯基，并对费多罗夫的退出深感愤怒。乌克兰空军副司令帕夫洛·叶利扎罗夫因费多罗夫的免职而辞职。他在辞职信中称，费多罗夫的辞职将削弱乌克兰的防空能力，对国防能力来说是巨大的祸害。
泽连斯基承认国防部和军方在多个层面上存在困难关系，双方都对后果负有责任。泽连斯基正考虑将内务部长伊戈尔·克利缅科作为国防部长的候选人之一，并相信费多罗夫仍将留在其团队中。
（美联社，CNN）

中国二季度GDP同比增4.3%、环比增0.9%。增速是2022年以来新低。
6月社会商品零售37924亿元、同比增0.9%，餐饮收入4767亿、同比增1.2%。
6月规上工业增加值同比增5.3%、环比增0.76%。
1–6月固定资产投资同比下降5.7%，扣除房地产后下降2.7%。其中国有控股投资同比降2.3%。坏于预期。
6月末商品房待售76315万平、同比降0.9%，其中住宅40865万平、同比持平。
上半年城镇居民人均可支配收入30126元（中位数26389）同比名义增4.4%、实际增3.4%；农村人均可支配收入12699元（中位数10649）同比名义增6.4%、实际增5.5%。
