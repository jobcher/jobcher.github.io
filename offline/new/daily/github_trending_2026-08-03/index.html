欧足联及其成员协会7月30日发表声明，反对国际足联将世界杯及其他国际足联赛事的所有权转让给私人投资者的提议，将抵制国际足联举办的各项赛事。 国际足联28日提议成立名为“国际足联前进公司（FFE）”的机构，负责转播、赞助等比赛商业事务，同时负责赛事的筹划和举办。该公司的资本规模为200亿美元，其中20%的股份将向外部投资者出售。而其中主要的投资者为特朗普女婿贾里德·库什纳的弟弟约书亚·库什纳。 （欧足联，国际足联，CNN）

国际足联主席因凡蒂诺7月31日宣布将不再推进成立“国际足联前进公司（FFE）”的提案，但质疑仍在。
FFE项目遭到了欧足联、中北美洲及加勒比海地区足联和亚足联的明确反对。因凡蒂诺在声明中解释称，FFE旨在为进一步加强国际足联成员协会和全球体育事业，但仔细听取各方意见后，该项目引发分歧，不再符合最初的目标。
欧足联欢迎国际足联的决定，但表示这项由“佚名”策划的、对比赛好处存疑的“秘密计划”被快速推进，必须查明责任人并追究责任。欧足联将联合其他足联密切合作，反思事件经过，制定计划确保此类事件不再发生。
欧足联直言“现任国际足联领导层不仅失去了欧足联的信任，也失去了许多足球大家庭成员的信任”，并点名批评因凡蒂诺没有兑现当初竞选时关于保持透明和将国际足联资金用于足球发展的两项承诺。
（国际足联，欧足联）
