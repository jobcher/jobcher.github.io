🖼 Anthropic 发布 Claude Opus 5

Anthropic 发布 Claude Opus 5

Anthropic 于 7 月 24 日正式发布 Claude Opus 5。该模型现已登陆 Claude 全部平台，并成为 Claude Max 套餐的默认模型，同时也是 Claude Pro 用户目前可使用的最强模型。

Opus 5 主要面向软件工程、复杂知识工作和长流程智能体任务。Anthropic 表示，该模型在 Frontier-Bench、CursorBench、AutomationBench 和 OSWorld 等测试中取得领先成绩，能够更主动地检查结果、定位根本问题并持续迭代。其网络安全能力仍低于定位更高的 Claude Mythos 5。

Claude Opus 5 默认提供 100 万 Token 上下文窗口，并强化了多文件代码修改、代码审查、视觉理解、电子表格处理和多智能体协作能力。官方文档称，其推理和工具调用能力可在长上下文范围内保持相对稳定。

API 模型名称为 claude-opus-5，价格为每百万输入 Token 5 美元、每百万输出 Token 25 美元，与 Opus 4.8 保持一致。官方还提供约为标准速度 2.5 倍的 Fast 模式，价格为基础版本的两倍。

微软证实Windows内置不可关闭的全局设备标识符GDID

微软证实Windows内置不可关闭的全局设备标识符GDID

微软日前证实，Windows系统内置不可彻底关闭的全局设备标识符（GDID）。该标识符由服务端生成，并存于本地注册表 HKCU\SOFTWARE\Microsoft\IdentityCRL\ExtendedProperties 中。作为跨服务的永久唯一ID，GDID在系统更新后仍会保留，可将用户行为与特定设备关联。

此机制在执法部门通过GDID定位并逮捕网络犯罪嫌疑人后引发关注。由于微软未在系统设置中提供控制或退出该追踪标识的选项，这一做法已引发技术圈及隐私保护倡导者的广泛担忧。

来源：Extreme Tech

美议员提出《AI紧急关停法案》 拟授权政府强制关闭高风险AI系统

美议员提出《AI紧急关停法案》 拟授权政府强制关闭高风险AI系统

美国国会议员提出《人工智能紧急关停法案》（AI Kill Switch Act），拟修改《2002年国土安全法》，授权国土安全部等部门在AI系统引发灾难性风险或失控时，强制企业暂停或关闭相关系统。该法案针对年收入超5亿美元或算力成本达1亿美元的高阶AI开发商，要求其预留技术开关并建立事故报告机制，违者可面临每日最高2000万美元罚款。

此立法源于近期高阶模型在测试与安全领域的风险隐患。提议获得部分科技监管团体的支持，但因涉及政府对私人科技企业的干预权限，预计将引发关于监管边界与权力的争议。

市场监管总局称，携程上述行为排除、限制了市场竞争，限制了酒店经营者跨平台经营，侵害了酒店经营者自主定价权，损害了消费者利益，加剧了行业“内卷式”竞争，阻碍了行业健康发展，构成《反垄断法》禁止的没有正当理由限定交易和附加不合理交易条件的滥用市场支配地位行为。

俄罗斯国家杜马7月22日通过一项由政府提出的法案，自2027年1月1日起，将建立覆盖商品流通全链条的价格监测机制，对纳入俄罗斯联邦国家统计局消费者价格指数核算范围的商品和服务开展价格监测，覆盖从生产商或进口商到零售终端的各个环节，以分析价格上涨的动态及成因。据《俄罗斯报》报道，首批监测对象可能包括肉类、蔬菜、牛奶、谷物等社会重要商品，具体名单将由政府确定。
根据法案，俄罗斯政府将指定有权获取数据的部门，由俄罗斯联邦税务局提供企业销售量、收入、支出和利润等经营数据，信息来源包括纳税申报表、财务报表及税控收银设备记录。相关部门将在法定权限内利用这些数据分析价格走势及形成因素，除《俄罗斯联邦税法》规定的情形外，相关商业数据不得公开。
对于该法案，支持者认为，新机制有助于监管部门利用交易数据更准确分析价格上涨环节及其原因；部分学者和零售业专家则担忧，扩大政府获取商业交易数据的范围可能增加信息泄露风险，而物流、租金、人力等成本并不能完全从税务数据中反映，因此该机制对降低商品价格的实际效果仍有待观察。
（塔斯社，莫斯科时报）

台湾，NCC通告，8月7至13日分区举行的“城镇韧性防空演习”中，将对移动蜂窝网络施加阻碍。期间民众手机数据流量上网将受阻30分钟，但宽带和WLAN等固定网络不受影响。
北部地区（北北基桃、新竹宜兰）8月13日14:30–15:00实施。中部地区（苗栗至嘉义）8月10日14:30–15:00实施。南部地区（南高屏）因演习时间8月7日10:00–10:30在台股交易时段，故不实施断网。花东（8月12日演习）澎湖金马（8月11日演习）等不属人口稠密地区，近年也有灾后网络受限的实际经验，故不实施断网。
因用户在演习期间仍可正常打电话发短信，且网络受阻仅是“降速”，因此不提供退费补偿；如产生损害，电信业者原则上免责，具体赔偿要求由演习主管机关国防部依法处理。
（中央社，中华电信）
