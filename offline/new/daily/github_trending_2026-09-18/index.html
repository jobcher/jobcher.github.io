阿里发布全模态模型Qwen3.8-Omni-Flash，音视频API大幅降价

此外，该模型API每小时音频和音视频输入价格分别降价超98%与93%。阿里同时开源了Qwen-MM-Plugins与Qwen-Live Harness，模型已正式上线千问AI平台。
