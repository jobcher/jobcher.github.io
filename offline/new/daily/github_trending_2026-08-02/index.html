马尔康“11·11”红旗大桥垮塌灾害调查报告公布

马尔康“11·11”红旗大桥垮塌灾害调查报告公布

新华社成都7月31日电 2025年11月11日16时许，四川省阿坝藏族羌族自治州马尔康市红旗大桥后缘山体突发滑坡灾害，导致桥梁右岸引桥及部分路基损毁，造成国道317线道路中断。由于预警及时、提前管控，未造成人员伤亡。

日前，四川省政府常务会议审议通过阿坝马尔康“11·11”红旗大桥垮塌灾害调查报告。经调查认定，红旗大桥右岸边坡地质条件复杂，岩体裂隙发育、强卸荷带深度大，库水抬升浸泡后岩体软化劣化、承载能力降低，加之通道建设扰动、桥梁荷载等因素叠加，突发水库诱发型基岩边坡坐落式深层滑坡，直接导致红旗大桥垮塌灾害发生。另外，调查还查明相关勘察单位未依规开展右岸引桥水库坍岸区域工程地质勘察和桥梁岸坡稳定性评价，勘察工作弄虚作假，致使桥轴线定位和桥梁设计缺少充分依据、部分工程防范措施不到位，埋下了安全隐患。同时暴露出在库区桥梁安全隐患排查整治、监测预警不到位等方面的问题。

调查组查明，红旗大桥右岸边坡地质条件复杂，岩体裂隙发育、强卸荷带深度大，库水抬升浸泡后岩体软化劣化、承载能力降低，加之受通道建设扰动、桥梁荷载等因素叠加，突发水库诱发型基岩边坡坐落式深层滑坡，带动右岸引桥基础移位，右岸引桥基础随坡体持续下坐，引桥桥墩在滑坡体带动下先后倾斜、折断、倒塌，是造成红旗大桥右岸引桥垮塌的直接原因。同时，调查还发现相关涉事企业存在勘察设计业务违法分包转包、项目建设管理责任落实不力、隐患排查治理工作不到位等问题。

调查组按规定已将涉嫌违法犯罪的有关人员问题线索及相关材料移交公安机关立案侦查。调查过程中发现的地方政府、有关部门及有关国有企业的公职人员履职方面的问题线索及相关材料，已移交相关干部管辖权的纪检监察机关依规依纪依法处理。相关企业存在的违法违规问题，已移交有关行业部门（单位）依法依规处理。

《国务院关于出境入境管理的规定》自9月15日起施行，对出入境中介服务机构实施备案管理。
禁止境外机构在境内提供出入境中介服务。
对准备前往“风险等级为最高级别”或“严重危及人身安全案件突发高发”的国家地区者，边检可劝阻其前往。
违反出口管制、技术进出口管理等规定，可能危害国家产业安全、技术安全的，可以决定不准其出境。
骗取出境入境证件、非法出境入境受到行政拘留处罚的，在境外违法犯罪、危害国家安全利益的，可以不准出境6个月~3年。
不准出境的决定，若有可能影响国家安全、刑事案件侦查等情形的，可以不告知当事人。
为他人申请出境、入境停留居留出具虚假邀请函等材料的，个人罚款5000~1万元，单位罚款1~5万元，并没收违法所得。
个人从事出入境中介服务的，没收违法所得，可以并处5000元以下罚款。
（中国政府网）
