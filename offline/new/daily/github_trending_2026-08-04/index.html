MiniMax H3 权重开放，支持原生音视频联合生成

MiniMax 已在 Hugging Face 开放 H3 视频生成模型的核心权重。当前仓库规模约为 499 GB，包含 FL2VA 和 Ref2VA 两组任务检查点，分别面向文本及首尾帧生成、多模态参考生成。H3 的核心生成网络为拥有 330 亿参数的稠密单流 Transformer，并采用 MiniMax H3 Community License 发布。

H3 能够统一处理文本、图像、视频和音频上下文，生成时长为 4 至 15 秒、帧率为 24 FPS，并原生输出 32 kHz 立体声音频。模型稳定支持中文、英语、日语、韩语等 11 种对话语言，也可生成多种横竖屏比例的视频。

本次开放的 H3-Base 可在本地生成 768p 音视频内容，支持文生音视频、首帧或尾帧驱动、首尾帧控制，以及结合图像、视频和音频素材的参考生成。官方模型卡提供了 SGLang、vLLM、Diffusers 和 ComfyUI 等部署路径。

不过，H3 的完整系统尚未全部开放。负责解析复杂多模态指令的 H3-Context-IR，以及将基础结果重新生成至 2K 的 H3-Regenerate-2K，目前仍需调用 MiniMax 托管服务。首批权重也只包含全注意力推理实现，原生稀疏注意力代码计划在后续更新中发布。因此， H3 核心模型权重已经开放，而官方完整 2K 工作流仍部分依赖云端 API。

来源：MiniMax 官方 Hugging Face
