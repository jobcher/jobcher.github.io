Meta 推出 Muse Image，预告 Muse Video

Meta于7月7日正式推出图像生成模型Muse Image，并发布Muse Video预览版。两款模型由Meta Superintelligence Labs开发，其中Muse Image已接入Meta AI应用及网页端，率先在美国Instagram Stories和部分国家WhatsApp上线，后续将拓展至Facebook、Messenger及广告创意工具。
