SpaceXAI 开源 Grok Build

SpaceXAI 开源 Grok Build

SpaceXAI 于 7 月 15 日宣布开源终端编程智能体 Grok Build，并将源代码发布至 GitHub。此次开放的是 Grok Build 的代理框架、命令行工具和终端界面，不包括 Grok 4.5 等模型的权重。

公开代码覆盖上下文组装、模型响应解析、工具调用分发、文件读写、代码搜索与命令执行，同时包括全屏终端界面，以及 Skills、插件、Hooks、MCP 服务器和子智能体等扩展机制。项目主要使用 Rust，第一方代码采用 Apache 2.0 许可证。

开发者可以自行编译 Grok Build，并通过 config.toml 接入本地模型或其他兼容推理服务。Grok Build 还支持交互式终端、脚本及 CI 无头运行，并可通过 Agent Client Protocol 嵌入代码编辑器。

需要注意的是，该 GitHub 仓库由 SpaceXAI 内部代码库定期同步，目前不接受外部代码贡献。此次开源发生在 Grok Build 因上传用户代码仓库和数据留存问题引发争议之后
