中央气象台发布台风、暴雨及次生灾害综合预警

中央气象台7月11日10时继续发布台风橙色预警。今年第9号台风“巴威”（强台风级）11日9时位于浙闽交界东偏南约460公里的东海东南部海面，中心附近最大风力14级。预计，“巴威”将以每小时30公里左右的速度向西北方向移动，逐渐靠近浙江南部沿海，并于12日凌晨在浙江三门至苍南一带登陆，登陆时为台风级，最大风力12～13级，之后转向偏北方向移动并逐渐减弱。
受台风影响，11日14时至12日14时，东海大部、黄海南部、台湾海峡及浙江、福建、上海、江苏沿海等地将有6～8级大风，部分海域和沿海地区风力可达9～11级、阵风12～13级，台风中心附近阵风可达14～16级。

同期，浙江、福建北部、台湾岛等地将有大到暴雨，部分地区有大暴雨或特大暴雨。其中，浙江东部和南部、福建北部局地降雨量可达250～500毫米，台湾岛中北部局地可达250～800毫米。

中央气象台同时发布暴雨红色预警。北京、天津北部、河北中北部、辽宁、吉林、四川盆地西部及陕西、山西、甘肃、云南等地也将出现暴雨，部分地区有大暴雨，局地特大暴雨。北京东北部和南部、河北中部和东北部局地降雨量可达250～280毫米。

部分地区还将伴有短时强降水、雷暴大风或冰雹。辽宁中部、河北中部和东北部、天津北部、浙江中北部及沿海部分地区可能出现10级以上雷暴大风，最大风力可达11级以上，局地不排除出现龙卷；北京东部和南部、河北、天津北部、浙江中南部、四川中部等地最大小时雨量可超过80毫米。

受持续强降雨影响，北京东部和南部、天津北部、河北中北部、辽宁北部、四川中部、甘肃东部等地发生中小河流洪水的风险较高，部分地区风险高。

北京、天津、河北、辽宁、吉林、浙江、福建、四川、陕西、甘肃等地还需防范滑坡、泥石流、崩塌等地质灾害，其中浙江东部局部地区为红色预警。红色和橙色预警区域内受威胁人员应按照当地防灾部门安排及时转移避险。

有关地区应密切关注台风路径和雨情、水情变化，海上船只及时回港避风，沿海地区加固设施。公众应尽量避免在强风强雨期间外出，远离河道、低洼地、山谷、陡坡及临时建筑，接到转移通知后立即撤离。

中国6万亿债务化解取得阶段性进展 地方财政迎缓解契机

彭博社汇编数据显示，在江苏、浙江、山东等大省带动下，截至今年6月底，中国定下的6万亿元（人民币，1万1416新元）隐性债务置换额度已经用了约94%，说明这轮债务处理接近尾声。

中国在2024年底批准，分三年（2024至2026年）实施的地方政府债务限额增加计划，每年两万亿元，核心目标是发行地方政府债券来置换原有的隐性债务，从而大幅减轻地方利息负担，腾出资金发展经济。

彭博社报道指出，若继续保持当前发行速度，这项三年期债务置换计划的剩余额度可能在本月或下月用完。
